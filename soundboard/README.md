# Mi Soundboard

App de soundboard para el móvil: un panel para subir y configurar tus audios y un tablero de pads para hacerlos sonar.

- [`pwa/`](pwa/): versión web instalable (HTML/JS, Web Audio, audios en IndexedDB).
- [`maui/`](maui/): app nativa Android en C# / .NET 10 MAUI, en capas con MVVM. El APK se genera con el workflow `Soundboard - compilar APK Android` en la pestaña Actions.
