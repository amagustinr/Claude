# Mi Soundboard (PWA)

- `index.html` + `manifest.webmanifest` + `sw.js` + `icon.svg`: versión instalable. Súbela a cualquier hosting estático con HTTPS
  (GitHub Pages, Netlify, Vercel) y en el móvil usa "Añadir a pantalla de inicio". Funciona sin conexión.

Los audios se guardan en IndexedDB del navegador, solo en ese dispositivo.
