📖 ¿Cómo se juega?
  1. Crea una sala y comparte el código o el enlace.
  2. Cuando todos marcan Listo, sale una letra al azar.
  3. Escribe una palabra con esa letra para cada categoría.
  4. El primero en completar todo canta ¡Basta! y la ronda se cierra para todos.
  5. Revisan las respuestas de los demás y rechazan las que no valen. Si más de la mitad la rechaza, vale 0.
  6. 100 puntos si nadie más la puso, 50 si se repite, 0 si está vacía, no empieza con la letra o fue rechazada.
